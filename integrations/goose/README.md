# Goose custom provider (PowerTokens)

Drop [`powertokens.json`](powertokens.json) into Goose’s `custom_providers` directory and set `POWERTOKENS_API_KEY`.

- macOS / Linux: `~/.config/goose/custom_providers/powertokens.json`
- Windows: `%APPDATA%\Block\goose\config\custom_providers\powertokens.json`

Get a key: [powertokens.ai](https://powertokens.ai/?utm_source=github&utm_medium=oss&utm_campaign=goose) · [API keys](https://www.powertokens.ai/en/api-keys?utm_source=github&utm_medium=oss&utm_campaign=goose) · [Models](https://powertokens.ai/models?utm_source=github&utm_medium=oss&utm_campaign=goose) · [Docs](https://docs.powertokens.ai/?utm_source=github&utm_medium=oss&utm_campaign=goose)
