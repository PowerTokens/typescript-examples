# Goose custom provider (PowerTokens)

Download [`powertokens.json`](https://raw.githubusercontent.com/PowerTokens/typescript-examples/main/integrations/goose/powertokens.json), drop it into Goose’s `custom_providers` directory, and set `POWERTOKENS_API_KEY`.

- macOS / Linux: `~/.config/goose/custom_providers/powertokens.json`
- Windows: `%APPDATA%\Block\goose\config\custom_providers\powertokens.json`
